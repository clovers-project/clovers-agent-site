# Clovers Agent v2 · 品牌使用规范

版本 2.0 / 2026-11-12

## 1. 设计基准

本系统以用户提供的新版定稿 `clovers-agent-final.svg` 为唯一轮廓基准。
保留聊天气泡外形、四叶草镂空、右上两条放射提示线和原有倾斜关系。默认版本逐字节复制原稿。
“会回应，也会认真思考”为本次设计包提出的传播文案，可根据产品内容调整。

## 2. 三种表情

| 状态 | 形态 | 适用场景 |
| --- | --- | --- |
| default | 原稿双胶囊眼睛 | 品牌主标识、待命、通用聊天 |
| coding | `>_`，左尖括号与右下划线 | 编写代码、开发协作、执行代码任务 |
| thinking | `><`，双尖括号向内 | 分析问题、认真思考、规划任务 |

Coding 是操作与编写状态；thinking 是推敲状态。二者不代表完成、错误或警告。
不要靠表情独自传达关键状态；搭配“正在编写”“正在思考”等可访问文字。

新增表情在 512 单位坐标中设计，围绕 `(236, 238)` 旋转 −12°。圆头笔画宽 18，半径 9。
左眼中心线为 `(184,216) → (211,238) → (184,260)`。
Coding 右眼为 `(256,260) → (288,260)`。
thinking 右眼为 `(288,216) → (261,238) → (288,260)`。
导出时将线条展开为同向填充子路径，不使用字体字符代替正式图形。

## 3. 净空、尺度与裁切

标志原始 `viewBox="0 -16 512 512"`。不要改成 `0 0 512 512`，否则会改变上下留白。
净空单位 x = 32 个源画板单位。可见外形含提示线，四周至少留 1x。
32 px 的默认 Logo 对应最小净空 2 px；48 px 表情对应 3 px。

- 默认图标：建议 ≥32 px。
- Coding / thinking：建议 ≥48 px，复杂背景可适当加大。
- 横排字标：建议宽 ≥220 px。
- 双行签名字标：建议宽 ≥180 px。
- 竖排字标：建议宽 ≥160 px。
- Favicon 的 16 px 导出属于小尺寸特例，优先识别轮廓。

头像在正方形画板中使用 80% 大小的完整 Logo 画板，适配圆形裁切；请使用成品，不额外放大。
maskable 应用图标采用更保守的 70% 画板比例，所有可见图形都在中心安全圆内。

## 4. 色彩系统

幸运绿 `#20A464` 与深叶绿 `#175D43` 来自原稿，不作调整。
嫩叶绿 `#C9EFBE`、纸白 `#F4F7F2`、夜林绿 `#102B22` 是本包定义的配套扩展色。

| 方案 | 主体 | 眼睛 | 建议背景 |
| --- | --- | --- | --- |
| primary | #20A464 | #175D43 | 白色 / 纸白 |
| reverse | #C9EFBE | #FFFFFF | 夜林绿 / 深色 |
| forest | #175D43 | #175D43 | 浅色 |
| green | #20A464 | #20A464 | 浅色，仅图形 |
| white | #FFFFFF | #FFFFFF | 深色或绿色 |
| black | #000000 | #000000 | 浅色、单色制版 |

正文和小字号文字优先使用深叶绿。幸运绿在白底上的文字对比度不足 4.5:1，不作为小字号正文色。
镂空区应显示背景，不新增白色填充层；在复杂照片上使用独立纯色承载面。
色彩按 sRGB 数字媒介交付，不提供未经打样的 CMYK 数值。

## 5. 字体与字标

品牌字标沿用旧包已转曲的 Inter SemiBold / Inter Medium，保留小写拼写。
横排适合导航和横向页眉；双行签名适合窄横向空间；竖排适合封面和中心构图。
交付字标中的图形与文字保持固定比例，整组等比缩放。
说明性文字可使用 Inter、微软雅黑或系统无衬线字体。字体不随包分发。

## 6. 动效规范

仅改变眼睛的透明度，外轮廓、四叶草与提示线固定。
SVG 使用 CSS 动画，缓动 `ease-in-out`，不依赖脚本。

循环 6.4 秒：

| 比例 | 时间（秒） | 状态 |
| --- | --- | --- |
| 0–23% | 0–1.472 | 默认 |
| 23–27% | 1.472–1.728 | 默认淡化到 Coding |
| 27–54% | 1.728–3.456 | Coding |
| 54–58% | 3.456–3.712 | Coding 淡化到 thinking |
| 58–90% | 3.712–5.760 | thinking |
| 90–94% | 5.760–6.016 | thinking 淡化到默认 |
| 94–100% | 6.016–6.400 | 默认 |

单次 1.2 秒：0–0.3 秒默认；0.3–0.66 秒淡化到目标；0.66–1.2 秒保持目标，此后停在目标表情。
栅格动画以 25 fps、40 ms 时间粒度采样，所以切换边界存在不超过一帧的采样偏差。
GIF 是纸白底，WebP 透明；单次 GIF 不含循环扩展，单次 WebP 播放次数为 1。不同查看器可能自行提供重复播放控制。

启用 `prefers-reduced-motion: reduce` 时，SVG 静止为默认表情。
WebP / GIF 不识别系统偏好，必须通过网页 `picture` 提供静态回退。
品牌展示可用循环动画；产品任务反馈应切换相应静态状态，而非依赖固定循环。

## 7. 使用禁例

不要拉伸、额外旋转、加外描边、阴影或渐变；不要更改四叶草结构。
不要移动眼睛、放大眼睛、移除右上提示线，或把努力思考作为错误标志。
不要在深色背景直接放置原稿深绿眼睛；使用 reverse / white。
不要用字库输入的 `>_` / `><` 覆盖在 Logo 上；使用本包正式表情文件。
不要混用旧版轮廓、旧版绿色和新版字标图形。

## 8. 交付与维护

资产根目录见 README；源文件集中在 `08-source`。
`geometry.json` 保存精确路径和新增表情参数；`expressions-editable.svg` 保存可调整的中心线。
`ASSET-MANIFEST.json` 与 `SHA256SUMS.txt` 用于验证交付完整性。
以 SVG 作为设计源；不要把放大后的 PNG 重新保存为“矢量”。
修改源后按 BUILD.md 重新生成对应资产，并重新核对预览、PDF 与校验清单。
