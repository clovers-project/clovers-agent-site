先理解 Agent 与宿主

Clovers Agent 是运行在 Clovers 宿主中的异步 Agent 后端。它接收统一事件，组织会话、路由与模型工具循环；平台连接、界面、消息呈现与能力调用由宿主和适配器负责。

组成 负责什么
Clovers 宿主 / 客户端 启动生命周期、连接平台、加载 Clovers 插件。console 是本文的示例宿主。
平台适配器 把平台消息转为事件属性，把发送与调用请求转为具体平台操作。
clovers_agent 消息准入、会话、场景路由、模型调用、工具循环、图片与记忆压缩。
工具插件 / Skill 向核心添加具体工具、场景、工作流、脚本和参考资料。

本网站是介绍与使用文档。品牌图形和表情是视觉素材，不表示 Agent 提供了一套固定 UI、实时状态面板或统一前端协议。

模型与核心配置

核心配置位于 [clovers_agent]，由宿主配置系统读取。console 示例使用当前工作目录的 clovers.toml；其他宿主的配置位置由其实现决定。完整可运行配置见快速开始。

模型配置 · 合并到现有 TOML 
[clovers_agent.api]
url = "https://your-provider.example/v1"
model = "your-model"
api_key = "your-api-key"
extra_body = {}

# 可选：摘要使用独立模型
[clovers_agent.apis.summary]
url = "https://your-provider.example/v1"
model = "your-summary-model"
api_key = "your-api-key"

默认模型必须支持 function tool calling。请求使用 Bearer 鉴权，目标地址为 url 去掉末尾斜杠后追加 /chat/completions。当前解析完整 JSON 响应，不支持模型 token 流式响应。

字段 / 接入点 用途
api 必填的默认模型配置。
apis.router / apis.on_chat 场景选择 / 普通聊天；缺失时回退默认模型。
apis.chime_in / apis.summary 主动插话 / 历史摘要。
apis.on_workspace 官方工具集工作区场景，路由入口实际名为 on_workspace。
vision 可在模型配置中指定独立视觉接入点，先把图片转写为文字。
extra_body 附加请求体，会合并并可覆盖 model、messages 等字段。
sentence_model 默认 BAAI/bge-small-zh-v1.5，用于句向量。
sentence_model_cache 句向量缓存路径，与数据根目录 path 分开配置。

消息准入与平台接入

从 console 迁移到聊天平台时，在所选宿主环境安装 Agent，再让宿主加载 clovers_agent。替换宿主入口、平台连接与适配器配置，并按实际群号设置准入。

群聊准入 · 替换原 check 段 
[clovers_agent.check]
whitelist = ["your-group-id"]
blacklist = []
console_mode = false

准入依次采用第一个满足的模式：非空白名单 → 非空黑名单 → console_mode → 拒绝全部。群号必须是字符串；白名单与黑名单模式都要求群聊，不接收私聊。不要同时配置多个模式并期待叠加。

接入前核对这些能力

  • 基础事件：用户 ID、昵称、群组 ID、@ 列表、to_me 与图片列表。
  • 回复能力：文本、图片、文件，以及所选扩展需要的发送方法。
  • 额外能力：引用上下文、群成员查询、指定私聊或跨群发送，是否由该适配器实现。
开放协议不代表所有平台都实现了同一能力

以适配器的实际支持为准。例如 console 尚未实现 flat_context 与群成员查询，语音 / 视频通常以下载链接发送，定向私聊仅允许当前事件发送者。页面样式、状态展示和交互方式也由宿主决定。

更多宿主与适配器资料见文末相关项目；本文不展开与 Agent 使用无关的框架实现细节。

会话、路由与任务

群聊使用 group_id 隔离会话；私聊使用 private-<user_id>。准入通过后，Agent 先记录短期消息，再根据是否为定向消息、会话是否忙碌选择处理路径。

  1. 收到定向消息

    @ 机器人等定向输入进入正式处理。存在多个场景时由路由模型选择，路由异常时回退普通聊天。

  2. 加载场景与工具

    准备上下文，按需加载分类工具；同一次模型响应内的多个工具调用并发执行。

  3. 任务中继续交流

    主任务运行时，新的定向消息可由旁路回复，或向主任务注入补充说明。

  4. 回复并记录

    结束调用链后保存完成轮次。普通群聊在会话空闲、无其他 @ 且冷却结束等条件下可触发主动插话。

常用配置 默认值 / 含义
max_call_depth 40；一条调用链最多请求模型的次数，不是工具调用总数。
chime_in_cooldown 3600 秒；主动插话冷却。
session.silence_size 10；短期消息窗口容量。
session.silence_timeout 3600 秒；短期消息保留时间。

记忆、数据与人设

核心记录完成轮次，并在轮数、时间或话题切换条件满足时生成 Markdown 摘要。默认数据根目录为 ./data/CloversAgent/，相对路径按宿主启动时的工作目录解释。

常用数据路径 · 部分目录按需产生 
data/CloversAgent/
├── sessions/
│   └── <session_id>/
│       ├── recorder.jsonl
│       └── histories/
├── prompts/
│   ├── STYLE.md
│   └── CHAT.md
├── usages/
└── workspace/

recorder.jsonl 是可清理的上下文记录，不是永久聊天存档。摘要压缩会删除该记录并留下摘要，每日维护也会清理过期会话的记录；短期消息、图片映射和路由窗口只存在内存。

核心不会自动检索旧摘要并读回上下文；需要历史召回时启用生活化扩展。图片映射重启后无法凭旧标签恢复。

调整人设与回复风格

在数据目录的 prompts/STYLE.md 写人设与风格，CHAT.md 写普通聊天规则；也可配置 prompts 对应字段。非空覆盖文件优先。文件不会自动创建，修改后重启宿主生效。

会话配置 默认值 / 含义
session.memory_size 240；完成轮数严格大于此阈值时尝试摘要。
session.memory_timeout 86400 秒；记忆超时与过期会话维护判断。
session.decouple_length 3000 字符；达到后尝试话题检测，不是 token 上限。

可选工具集与工作区

clovers-agent-toolkit 提供工作区、联网搜索、网页正文提取和开发调试。在快速开始创建的 clovers-bot 项目目录中，从 PyPI 添加依赖，再加入核心的工具插件列表。

终端 · 在宿主项目目录执行 
uv add clovers-agent-toolkit
配置片段 · 合并并替换已有同名段，不要重复声明 
[clovers_agent]
plugins = ["clovers_agent_toolkit"]
plugin_dirs = []
skill_dirs = []

[clovers_agent_toolkit]
use_categories = ["workspace", "network"]

[clovers_agent_toolkit.workspace]
use_shell = false

[clovers_agent_toolkit.network]
deepseek_search_key = "your-search-api-key"
能力 使用条件与边界
文件工作区 默认无需 Docker，提供 fetch_url、ls、read_file、write_file；工作区可上传文件，依赖平台文件发送。
Docker 命令与子代理 设置 workspace.use_shell=true，且 Docker 初始化成功后注入 execute_command、subagent。失败时回退文件模式。
联网搜索 需要填写 network.deepseek_search_key；搜索结果是摘要，网页正文由 web_extractor 提取。
网页提取 HTTP 下载并提取正文，不提供浏览器 JS 渲染或登录流程。
开发调试 debug_utils 默认关闭，确有需要时再加入 use_categories。

保存配置后，用 uv run bot.py 重启宿主。子代理异步运行；主调用链空闲且已登记任务完成后，由唤醒轮次处理结果。它依赖当前进程，不是持久化任务队列。文件工具不能视为严格的宿主文件沙箱，启用前应按宿主的实际权限安排工作区。

生活化扩展

clovers-agent-life-extensions
在普通聊天中加入历史召回、用户画像与更多表达工具。

扩展已发布到 PyPI，需要 Python 3.12+ 与 clovers-agent>=0.3.8。先完成核心模型与准入配置，再在同一个宿主项目目录中添加依赖，并交给核心加载。

终端 · 在宿主项目目录执行 
uv add clovers-agent-life-extensions
替换现有 clovers_agent 段 · 仅保留已安装的扩展 
[clovers_agent]
plugins = [
  "clovers_agent_toolkit",
  "clovers_agent_life_extensions",
]
plugin_dirs = []
skill_dirs = []

上述示例同时启用工具集与生活化扩展；只安装了生活化扩展时移除工具集模块名。保存配置后，用 uv run bot.py 重启宿主。

能力 实际行为
历史召回 检索核心生成的 Markdown 摘要，混合关键词与语义排序，按需展开正文；最新的一条暂留摘要不会立即参与召回。
用户画像 按用户 ID 维护称呼、标签、偏好、印象与星级记忆；画像跨会话共用，历史按会话隔离。
贴纸 收藏当前消息图片，按意图筛选并发送。依赖图片资源和适配器。
语音 配置 TTS 与参考音频后注册 send_voice，发送能力由适配器提供。
定向消息 从群聊私聊当前用户，或向其他指定群发送文字。工具返回 OK 表示提交后台发送。

可选语音配置

配置 clovers_agent_life_extensions.chat.mimo_tts 的 url、model、api_key，并在核心数据目录 chat_utils/ref_voice.wav 放参考音频。音频可用且密钥非空才会注册语音工具，修改后重启。

历史召回、画像注入和这些工具绑定在 on_chat 场景。用户拉黑检查在路由前执行，主动插话与旁路回复不经过同一检查。画像与历史以本地明文保存，内容可能进入模型上下文，应按需要备份。

编写插件与 Skill

需要访问宿主对象或第三方库时使用 Python 工具插件；需要组织场景提示、工作流、脚本与参考资料时使用 Skill。两者由核心加载，区别于宿主加载核心本身。

扩展方式 加载配置 适用场景
已安装的 Python 工具模块 clovers_agent.plugins 导出 TOOLS = AgentTools() 的工具插件。
本地 Python 工具目录 clovers_agent.plugin_dirs 宿主环境下的本地工具开发。
Markdown Skill 根目录 clovers_agent.skill_dirs 扫描直接子项 .md 或带 SKILL.md 的目录。
自定义扩展 · 按需合并 
[clovers_agent]
plugins = []
plugin_dirs = ["./my_agent_tools"]
skill_dirs = ["./my_agent_skills"]

Skill 使用 UTF-8 Markdown 与 YAML front matter，name 和 description 必填。Python 插件的注册接口与 Skill 的参数结构不同，编写时参考各自文档。

Python 工具、Skill Python 与脚本拥有宿主权限；只加载你需要且信任的内容。仓库中的测试工具与风格示例并非必需功能，快速开始已清空默认扫描目录。

常见问题

启动了，但没有回复？

先确认宿主加载了 clovers_agent，api 配置有效，check 规则放行。群号使用字符串；用 @ 机器人或昵称前缀发送定向消息。console_mode 仅放行消息，不会把所有消息都变成定向输入。

启动卡在模型加载？

核对句向量模型的网络、缓存与路径。首次启动会加载 PyTorch / sentence-transformers 模型，准备本地模型后可调整 sentence_model 与 sentence_model_cache。

没有自动生成 clovers.toml？

console 的最小入口不会保存配置。手动创建快速开始中的文件，并始终从包含该文件的工作目录启动。修改配置后重启。

缺少 FastAPI / uvicorn 或 console/page？

在宿主项目目录执行 uv add "clovers-client[console]"，再用 uv run bot.py 启动，确保使用同一环境。console/page 缺失则是配套已构建网页资源缺失，检查安装产物是否包含它们；安装 Python 依赖不会替你构建网页。

安装了扩展，为什么工具没出现？

安装后还需要加入 clovers_agent.plugins 并重启。生活化扩展工具绑定在普通聊天场景，语音还需要有效参考音频和 TTS 配置。分类工具可能需要由模型按需加载。

重启后为什么记忆或旧图片不见了？

短期窗口与图片映射只存内存；完成轮次可能已压缩为摘要或被每日维护清理。核心没有自动历史检索，长期召回需生活化扩展。

文件、语音或跨群消息发送失败？

核对平台适配器是否实现对应发送方法，并查看后台日志。console 首次发送本地文件前需创建 data/CloversConsole/stores_dir/file/；定向私聊仅支持当前事件发送者。

模型请求失败，应查看什么？

查看宿主日志及会话目录中的 payload_*.json。核对 API 根地址、密钥、模型的工具调用支持与响应格式。失败现场可能含完整对话和工具内容，分享前先检查。
