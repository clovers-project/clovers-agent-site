GET STARTED / 快速开始

先让它回应一句。

用 uv 从 PyPI 安装依赖，以 clovers_client.console 作为宿主，在本地跑通 Agent。

Python 3.12+console 宿主示例
STEP 01

安装 uv，创建运行项目

uv 用来管理 Python、项目依赖与运行环境。先安装 uv，再从 PyPI 安装 Agent 与 console 宿主。另需准备一个支持 function tool calling 的 OpenAI 兼容 Chat Completions 模型接入点。

安装 uv

按操作系统选择安装命令。已安装 uv 的读者可以直接检查版本，继续创建项目。

PowerShell · 安装 uv 
winget install --id=astral-sh.uv -e
Shell · 安装 uv 
curl -LsSf https://astral.sh/uv/install.sh | sh

安装后重新打开终端，检查 uv 是否可用：

终端 · 检查 uv 
uv --version

其他安装方式：uv 官方安装指南 ↗

创建项目并安装依赖

在你希望存放机器人的目录执行以下命令。示例使用 Python 3.12，并声明核心支持的 Python 范围。

终端 · 创建 clovers-bot 
uv python install 3.12
uv init --bare --python ">=3.12,<4.0" clovers-bot
cd clovers-bot
uv python pin 3.12
uv add clovers-agent "clovers-client[console]"

uv python install 安装 Python，uv init 创建项目，uv python pin 固定本项目使用的解释器版本；uv add 从 PyPI 添加依赖并管理 .venv 与 uv.lock。后续始终在 clovers-bot 中执行命令，用 uv run 运行脚本即可。

pyproject.toml 记录项目依赖，uv.lock 记录解析后的确切版本。换机器时带上这两个文件及项目文件，在项目目录执行 uv sync 即可恢复依赖环境。

首次启动需要句向量模型

核心使用 PyTorch / sentence-transformers，首次启动需要获取句向量模型，或提前准备本地模型与缓存。这里先运行核心，工具集和其他扩展可在跑通后按需安装。

参考：uv 项目使用指南 ↗ · 客户端使用文档 ↗

STEP 02

创建宿主入口

在刚才创建的 clovers-bot 目录中，与 pyproject.toml 同级创建 bot.py。这段代码启动的是 clovers_client.console 宿主，它负责加载 Agent 插件并提供本地 HTTP / WebSocket 服务。

bot.py 
import asyncio

from clovers_client.console import Client

asyncio.run(Client().run())

STEP 03

配置模型与消息准入

在 bot.py 旁手动创建 clovers.toml，粘贴下面的完整配置，并替换模型地址、模型名和 API Key。

clovers.toml 
[clovers]
BOT_NICKNAME = "小叶子"
plugins = ["clovers_agent"]
plugin_dirs = []

[clovers_agent]
plugins = []
plugin_dirs = []
skill_dirs = []

[clovers_agent.api]
url = "https://your-provider.example/v1"
model = "your-model"
api_key = "your-api-key"

[clovers_agent.check]
console_mode = true

下载配置模板 ↓

配置位置 作用
[clovers].plugins 宿主加载核心模块 clovers_agent。
[clovers_agent].plugins 核心加载工具扩展；本例留空，先验证基本对话。
plugin_dirs / skill_dirs 本例清空示例扫描目录，后续按需指定自己的插件和 Skill。
api.url 填写 API 根路径，例如以 /v1 结尾；核心会追加 /chat/completions。
check.console_mode 本地联调时放行消息；它是准入开关，控制台由宿主创建。
配置完成后再启动

console 的最小入口不会自动生成配置文件。默认的 Agent 准入规则不接收任何消息；本例通过 console_mode 放行。API Key 只写入本地宿主配置，不应提交到公开仓库。

STEP 04

启动，发送第一条消息

保持终端位于同时包含 pyproject.toml、bot.py 与 clovers.toml 的 clovers-bot 目录，运行：

终端 · 启动宿主 
uv run bot.py

在浏览器打开 http://127.0.0.1:11000/ ↗。在 console 中 @ 机器人，或以昵称开头发送：

尝试发送

小叶子你好，介绍一下你自己。

看到模型回复，说明“消息 → 宿主 → Agent → 模型 → 回复”的链路已跑通。普通私聊本身不自动视为定向消息，因此先使用 @ 或昵称前缀验证。按 Ctrl + C 停止宿主；修改配置后重启。

网页控制台来自宿主

Agent 不包含独立前端。console 需要安装产物中带有配套的已构建网页资源；若日志提示 console/page 不存在，请检查 clovers-client 安装产物，详见排查文档。
